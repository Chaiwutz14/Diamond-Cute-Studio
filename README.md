# Diamond Cute Studio

เว็บหน้าร้านสำหรับเลือกชมสินค้า สิ่งพิมพ์ และตัวอย่างผลงาน พร้อมเส้นทางสั่งซื้อและติดตามงาน ออกแบบสำหรับลูกค้าบนมือถือและเดสก์ท็อป

*A responsive storefront for browsing printed products, viewing work samples, and placing and tracking orders.*

[เปิดเว็บไซต์ตัวอย่าง](https://chaiwutz14.github.io/Diamond-Cute-Studio/)

## ภาพรวม

Repository นี้ประกอบด้วยหน้าเว็บไซต์และส่วนติดต่อผู้ใช้ของ Diamond Cute Studio เขียนด้วย HTML, CSS และ JavaScript โดยไม่ต้องติดตั้ง dependency เพื่อเปิดดูหน้าเว็บแบบพื้นฐาน

## ความสามารถหลัก

- เรียกดูสินค้า หมวดหมู่ และตัวอย่างผลงาน
- ดูรายละเอียดสินค้าและตัวเลือกปรับแต่งที่มีในแต่ละรายการ
- จัดการสินค้าในตะกร้าและดำเนินขั้นตอนสั่งซื้อ
- ดูข้อมูลการติดตามงานผ่านหน้าที่จัดเตรียมไว้
- ใช้หน้าสำหรับผู้ดูแลร้านที่อยู่ในชุดไฟล์ของเว็บไซต์
- รองรับการติดตั้งเป็นเว็บแอปผ่านไฟล์ PWA ของโครงการ
- แสดงแบนเนอร์และปุ่มหมวดหมู่ที่ออกแบบให้เหมาะกับจอหลายขนาด

รายละเอียดการทำงานบางส่วนอาจขึ้นกับสภาพแวดล้อมที่เปิดเว็บไซต์ เอกสารนี้จึงไม่ระบุข้อมูลเชื่อมต่อหรือขั้นตอนปฏิบัติการของบริการภายนอก

## โครงสร้างโครงการ

| รายการ | ใช้สำหรับ |
| --- | --- |
| `index.html`, `catalog.html`, `product.html` | หน้าแรก แคตตาล็อก และรายละเอียดสินค้า |
| `cart.html`, `orders.html` | ตะกร้า/ขั้นตอนสั่งซื้อ และหน้าติดตามงาน |
| `gallery.html`, `about.html`, `contact.html` | ตัวอย่างผลงานและข้อมูลสำหรับลูกค้า |
| `css/` | รูปแบบและการจัดวางหน้าเว็บ |
| `js/` | พฤติกรรมและส่วนโต้ตอบของเว็บไซต์ |
| `assets/` | รูปภาพ ไอคอน และสื่อที่ใช้ในหน้าเว็บ |
| `tests/` | ชุดตรวจ regression และ browser QA |

## เปิดดูในเครื่อง

ต้องมี Python 3 เพื่อเปิดเว็บเซิร์ฟเวอร์เฉพาะเครื่อง:

```bash
python -m http.server 8080
```

จากนั้นเปิด `http://localhost:8080` ในเบราว์เซอร์ หากคำสั่งในระบบใช้ชื่อ `python3` ให้ใช้ `python3 -m http.server 8080` แทน

## ตรวจสอบการเปลี่ยนแปลง

ชุด regression ใช้ Node.js test runner:

```bash
node --test tests/site-regression.test.mjs
```

Pull request ที่ส่งเข้า `main` มี browser และ responsive QA ใน GitHub Actions ดูแนวทางส่งการเปลี่ยนแปลงได้ที่ [CONTRIBUTING.md](CONTRIBUTING.md)
